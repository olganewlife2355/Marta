# Sourcing Desk (MVP, етап 1)

Локальний застосунок для сорсингу та скорингу кандидатів. Відкривається в браузері, але працює на вашому комп'ютері. Дані зберігаються в одному файлі `data/sourcing.db`.

## Що вміє

| Розділ | Що робить |
|---|---|
| 📋 Вакансії | JD + нотатки kick-off → Claude генерує scorecard: must-have, nice-to-have, red flags, **компанії-донори з тирами**. Усе можна відредагувати, налаштувати ваги скору |
| 📥 Імпорт | CSV з Juicebox, LinkedIn Recruiter або будь-якої таблиці. Колонки підбираються автоматично, можна поправити вручну. Або додати кандидата вручну |
| 🏆 Шортлист | Скор 0-100 по кожному кандидату з доказами з профілю. Бейдж хантабельності за стажем у поточній компанії. Фільтри: скор, "12+ міс.", статус |
| 🤝 Кого додати сьогодні | Черга на інвайти в LinkedIn: спочатку 🟢 кандидати з найвищим скором + готова персональна нотатка. Лічильник тижневого ліміту |
| ⏰ Нагадування | Кому писати сьогодні (дата "наступного дотику") + список теплого нетворку |
| ⚙️ Налаштування | Статус ключа, модель, експорт пайплайну в CSV |

### Як рахується скор

| Частина | Вага за замовч. | Джерело |
|---|---|---|
| Must-have критерії | 35 | Claude, з вагою кожного критерію 1-5 |
| Nice-to-have | 10 | Claude |
| Компанія-донор | 25 | Автоматично: поточна компанія T1=100, T2=70, T3=40; донор у минулому досвіді = половина |
| Домен (b2c, subscription, mobile, edtech) | 15 | Claude |
| Сеньйорність | 15 | Claude |

Ваги змінюються на сторінці вакансії.

### Бейджі хантабельності

- 🟢 12-36 міс. у компанії: оптимальне вікно
- 🟡 понад 36 міс.: довго на місці, перевірити стагнацію
- 🔴 до 12 міс.: рано
- ⚪ немає даних про дату старту

## Встановлення (один раз)

1. Встановіть Python 3.10+ з [python.org](https://www.python.org/downloads/). На Windows під час встановлення поставте галочку **"Add Python to PATH"**.
2. Скачайте папку `sourcing-app` на комп'ютер.
3. Скопіюйте файл `.env.example` у `.env` і вставте ключ Claude API в рядок `ANTHROPIC_API_KEY=` (ключ створюється на console.anthropic.com).

## Запуск

- **Windows:** подвійний клік на `start.bat`
- **Mac:** подвійний клік на `start.command`. Якщо Mac блокує запуск: правий клік → Open

Перший запуск триває 1-2 хв (встановлюються бібліотеки). Далі застосунок відкривається в браузері за адресою `http://localhost:8501`.

Без ключа API застосунок теж працює: scorecard заповнюється вручну, доступний швидкий скор за донорами, бейджі стажу та CRM.

## Перший прогін

1. «Вакансії» → нова вакансія → вставити JD і kick-off → «Згенерувати scorecard» → перевірити список донорів → «Зберегти».
2. «Імпорт» → завантажити CSV (для тесту є `sample_data/candidates_sample.csv`).
3. «Шортлист» → «Оцінити нових через Claude».
4. «Кого додати сьогодні» → відкрити профіль, вставити нотатку, надіслати інвайт у LinkedIn → «Інвайт надіслано» (нагадування через 7 днів ставиться автоматично).

## Важливо

- Застосунок **нічого не надсилає в LinkedIn сам** і не скрейпить його. Автоматизація LinkedIn порушує його правила і веде до бану акаунта.
- У базі зберігаються персональні дані кандидатів. Не кладіть `data/` у спільні папки без потреби, видаляйте неактуальні записи (GDPR).
- Модель за замовчуванням `claude-opus-5-5`. Для великих обсягів можна поставити дешевшу `claude-sonnet-5-5` у `.env` (`SOURCING_MODEL=`). Перед тим порівняйте якість на 10-20 відомих вам кандидатах.

## Наступні етапи

- Chrome-розширення "Зберегти профіль" для профілю, який ви переглядаєте
- Gmail nurture-кампанії для теплого нетворку
- Slack-дайджест "кого додати сьогодні"
- Передача кандидата в BambooHR, імпорт kick-off з Metaview
