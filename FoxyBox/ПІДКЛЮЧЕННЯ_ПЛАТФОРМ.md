# 🦊 FoxyBox — підключення платформ до центру постингу

FoxyBox поступово стає одним центром управління постингом. Telegram уже
працює (пости + дашборд). Щоб підключити решту платформ, потрібні «ключі» —
так само, як ви колись отримували api_id/api_hash на my.telegram.org.

Цей файл — покрокова інструкція, що і де отримати. Реєстрації можна
проходити у будь-якому порядку і в зручному темпі. Коли отримаєте ключі
з якоїсь платформи — скажіть Claude, і він підключить її до FoxyBox.

> 🔒 Усі ключі й токени — приватні. Нікому не пересилайте, нікуди не
> викладайте. Вони зберігатимуться тільки у файлі `foxybox_connectors.json`
> на вашому компʼютері.

## Що можливо на кожній платформі (чесна таблиця)

| Платформа | Постинг | Обмеження |
|---|---|---|
| Telegram (ваші канали/групи) | ✅ вже працює | перегляди є лише в каналах |
| Threads | ✅ офіційний API | — |
| Facebook | ⚠️ тільки Сторінка (Page) | в особистий профіль API не постить — таке правило Meta для всіх |
| Instagram | ⚠️ Business/Creator | лише пости з фото/відео; текстових постів в IG не існує |
| LinkedIn особистий | ✅ офіційний API | — |
| LinkedIn сторінка компанії | ⚠️ потрібне схвалення LinkedIn | заявка розглядається тижнями |

## Реєстрація 1. Meta — одна на Threads + Facebook + Instagram (~20 хв)

Один «застосунок Meta» покриває одразу три платформи.

1. Відкрийте **https://developers.facebook.com** і увійдіть своїм
   акаунтом Facebook.
2. Якщо сайт попросить — підтвердьте акаунт розробника (це безкоштовно:
   погодитись з умовами, підтвердити email або телефон).
3. Натисніть **My Apps → Create App**.
4. На питання про use case оберіть **Other → Business** (або просто
   Business, якщо питання інше — інтерфейс Meta часто змінюється).
5. Назва застосунку: `FoxyBox` (або будь-яка). Email — ваш. **Create App**.
6. Ви потрапите в панель застосунку. Запишіть собі два значення зі
   сторінки **App Settings → Basic**:
   - **App ID** (число)
   - **App Secret** (натисніть Show, введіть пароль FB)
7. У розділі **Add Products** (або Use cases) додайте:
   - **Threads API** — для Threads
   - **Instagram** — для Instagram
   - **Facebook Login for Business** — для Сторінки FB
   (якщо якогось нема у списку — нічого страшного, підключимо пізніше)

**Це все, що треба на цьому етапі.** Токени доступу ми згенеруємо разом,
коли Claude підключатиме кожну платформу — там є нюанси, які простіше
пройти в діалозі.

### Додатково для Facebook: створіть Сторінку

В особистий профіль постити через API неможливо, тому потрібна Сторінка:

1. У Facebook натисніть свій аватар → **Pages / Сторінки** → **Create new Page**.
2. Назва — імʼя вашого проєкту/компанії, категорія — наприклад «Recruiter».
3. Готово. 5 хвилин.

### Додатково для Instagram: звʼязати з Сторінкою

У вас уже Business/Creator — чудово. Тепер звʼяжіть його зі Сторінкою:
Instagram → Налаштування → «Центр акаунтів» / «Повʼязані акаунти» →
додайте створену Сторінку Facebook.

## Реєстрація 2. LinkedIn (~15 хв)

1. Відкрийте **https://developer.linkedin.com** → **Create App**.
2. Назва: `FoxyBox`. LinkedIn Page — тут вкажіть **сторінку вашої компанії**
   (застосунок мусить бути привʼязаний до якоїсь сторінки).
3. Погодьтесь з умовами → **Create App**.
4. У вкладці **Auth** запишіть:
   - **Client ID**
   - **Client Secret**
5. У вкладці **Products** натисніть **Request access** для:
   - **Share on LinkedIn** — постинг від вашого імені (схвалюється миттєво)
   - **Sign In with LinkedIn using OpenID Connect** — вхід (миттєво)
   - **Community Management API** — постинг від імені сторінки компанії.
     ⚠️ Це заявка з формою: LinkedIn питає, навіщо вам доступ. Пишіть чесно:
     «Publishing job openings to our own company page». Розгляд — від кількох
     днів до кількох тижнів. Особистий постинг працюватиме, не чекаючи цього.

## Що далі

Отримали ключі з будь-якої платформи → повертайтесь до Claude зі словами
«я маю ключі від …» (самі ключі в чат не вставляйте — Claude скаже, у який
файл на компʼютері їх вписати). Далі він додає платформу в FoxyBox:
у вкладці «Пости в групи» зʼявляться галочки платформ, а в Дашборді — їхня
статистика.

Порядок підключення — будь-який. Найшвидші результати зазвичай:
**Threads → LinkedIn особистий → Facebook Сторінка → Instagram →
LinkedIn компанії** (останній — коли LinkedIn схвалить заявку).
