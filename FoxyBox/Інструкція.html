FoxyBox

Тепла розсилка перших повідомлень кандидатам у Telegram з вашого акаунта. Ось як встановити з нуля.

≈ 15 хвилин Без технічних знань
Спершу про безпеку. Холодна розсилка порушує правила Telegram і може обмежити акаунт. Тому:
  • для перших тестів беріть запасний акаунт, не основний робочий;
  • тримайте ~20–30 повідомлень на день, паузи не скорочуйте;
  • великі списки розбивайте на кілька днів;
  • якщо вискочив PeerFlood — пауза 1–2 дні, далі не слати.
Спокійно, це простіше, ніж здається. Вам не треба нічого програмувати, не треба знати команди напам'ять і не треба вставляти жодних «промтів» чи коду з інтернету. Ви лише копіюєте готові рядки звідси й тиснете Enter. Просто йдіть крок за кроком.

Розпакувати файли на Робочий стіл

Ви отримали всі файли одним архівом — FoxyBox-встановлення.zip (наприклад, у Завантаженнях або в Telegram).

  1. Двічі клацніть по FoxyBox-встановлення.zip — він розпакується, і поряд зʼявиться папка FoxyBox.
  2. Перетягніть цю папку FoxyBox на Робочий стіл (Desktop) — щоб її було легко знайти.
  3. Перетягніть цю папку FoxyBox на Робочий стіл — щоб її було легко знайти.

Усередині папки буде кілька файлів. Ось що є що (нічого звідти не виймайте):

  • foxybox.py — сам застосунок (сюди впишете ключі на кроці 5)
  • index.html — вигляд застосунку, чіпати не треба
  • FoxyBox.command — кнопка запуску (Mac)
  • FoxyBox.bat — кнопка запуску (Windows)
  • Інструкція.html — ця сама інструкція
Головне правило: усі файли мають лишатися разом в одній папці. Не перекладайте їх поодинці — FoxyBox шукає їх поруч.

Що таке Термінал? Це вбудована програма Mac, де замість кнопок ви вводите короткі команди текстом. Лякатись не варто: ви лише вставлятимете готові рядки звідси, а комп'ютер усе зробить сам.
Що таке Командний рядок? Це вбудована програма Windows, де замість кнопок ви вводите короткі команди текстом. Лякатись не варто: ви лише вставлятимете готові рядки звідси, а комп'ютер усе зробить сам.

Встановити Telethon

Telethon — це «перекладач», через який FoxyBox спілкується з Telegram.

У тому самому вікні, що й у кроці 1 (Термінал / Командний рядок), вставте команду нижче — так само: скопіюйте (Cmd + C)(Ctrl + C), клацніть у вікно, вставте (Cmd + V)(права кнопка миші або Ctrl + V) і натисніть Enter:

pip3 install telethon
pip install telethon
pip install tzdata

Зачекайте кілька секунд — побіжить текст. Коли внизу зʼявиться Successfully installed telethon-… — готово, крок виконано.

Навіщо tzdata: у Windows нема системної бази часових поясів, а вона потрібна для скидання денного ліміту о 00:00 CET. Якщо забудете — FoxyBox сам нагадає про цю команду при запуску.

Отримати два ключі від Telegram

Щоб застосунок міг заходити у ваш Telegram, потрібні api_id і api_hash. Їх безкоштовно видає сам Telegram.

  1. Відкрийте my.telegram.org, увійдіть за номером телефону (краще запасного) і кодом із Telegram.
  2. Натисніть API development tools.
  3. Заповніть тільки два поля: App title = FoxyBox, Short name = foxybox. Поля URL і Description лишіть порожніми, Platform — Desktop.
  4. Натисніть Create application.
  5. Скопіюйте два значення: api_id (коротке число) і api_hash (довгий рядок).
Приватне: ці ключі нікому не пересилайте й нікуди не викладайте.

Вписати ключі у програму

Як відкрити файл: у папці FoxyBox клацніть по foxybox.py правою кнопкою миші → Відкрити у програмі → TextEdit.

Як відкрити файл: у папці FoxyBox клацніть по foxybox.py правою кнопкою миші → Відкрити за допомогою → Блокнот (Notepad).

Угорі файлу знайдіть два рядки, що починаються з API_ID і API_HASH. Замініть у них значення на свої з кроку 4 — число без лапок, а хеш обовʼязково в лапках:

API_ID = 1234567
API_HASH = "ВАШ_ХЕШ_СЮДИ_У_ЛАПКАХ"

1234567 і текст у лапках — це лише приклад формату. Зітріть його і впишіть свої два значення. Потім збережіть файл: Cmd + SCtrl + S, і закрийте редактор.

Готово! Після «Ви увійшли» браузер відкриється сам. Вхід більше не питатиме — далі просто двічі клацаєте ярлик. 🎉
Як користуватись

1. Запуск. Двічі клацніть FoxyBox.commandFoxyBox.bat — за кілька секунд відкриється браузер із застосунком.

2. Розсилка. У вікні застосунку два поля. У перше впишіть текст повідомлення (опис вакансії своїми словами). У друге — список @username кандидатів, по одному в рядку. Натисніть «Запустити розсилку». Паузи, базу й денний ліміт FoxyBox веде сам.

3. Зупинити. Закрийте вікно Терміналу або натисніть у ньому Ctrl + C.

Нічого «програмувати» чи вставляти жодних «промтів» не треба. Єдине, що ви вписуєте у застосунок, — свій текст вакансії та список @username. Це все.
Порада на перший раз: впишіть у список свій власний @username і надішліть повідомлення собі — воно прийде у «Збережені повідомлення» (Saved Messages). Так ви безпечно переконаєтесь, що все працює, нікого не потурбувавши.
Якщо щось пішло не так
Браузер не відкрився / Термінал закрився з помилкою

Найчастіше це збій входу. Відкрийте файл foxybox.log у папці — в останніх рядках буде причина (найпоширеніші — нижче).

Пише про невірний пароль (PasswordHashInvalidError)

На акаунті увімкнена двоетапна перевірка, а на кроці пароля ви натиснули Enter. Запустіть ще раз і введіть свій хмарний пароль Telegram (Налаштування → Конфіденційність → Двоетапна перевірка). Це не код і не пароль від пошти.

Код не приймається або просить почати спочатку

Старий код стає недійсним. Запустіть ярлик заново і введіть новий код із Telegram.

macOS не відкриває файл «від невідомого розробника»

Клацніть по FoxyBox.command правою кнопкою → Відкрити → Відкрити. Достатньо один раз.

Windows показує «Захист системи SmartScreen»

Натисніть «Докладніше» → «Виконати в будь-якому разі». Це стандартне попередження для файлів, завантажених з інтернету.
