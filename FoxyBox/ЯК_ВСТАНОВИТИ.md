# 🦊 FoxyBox — покрокова інструкція встановлення

FoxyBox — це маленький застосунок для теплої розсилки перших повідомлень
кандидатам у Telegram з вашого особистого акаунта. Працює **повністю на вашому
комп'ютері**, нічого не надсилає на чужі сервери.

Основна інструкція нижче — для **macOS**. Для **Windows** усе те саме, лише з
трьома дрібними відмінностями — вони зібрані в окремому розділі
[«Якщо у вас Windows»](#-якщо-у-вас-windows) наприкінці. Усе разом займає
**10–15 хвилин**. Технічних знань не потрібно — просто робіть крок за кроком.

> ⚠️ **Важливо про безпеку (прочитайте перед початком).**
> Масова холодна розсилка порушує правила Telegram і може призвести до
> обмеження акаунта. Тому:
> - для перших тестів беріть **запасний акаунт**, не основний робочий;
> - тримайте **~20–30 повідомлень на день**, паузи не скорочуйте;
> - великі списки розбивайте на кілька днів;
> - якщо Telegram видасть **PeerFlood** — пауза 1–2 дні, далі не слати.

---

> **Спокійно, це простіше, ніж здається.** Вам не треба нічого програмувати,
> знати команди напам'ять чи вставляти якісь «промти» або код з інтернету.
> Ви лише копіюєте готові рядки звідси й тиснете Enter. Просто йдіть крок за кроком.

## Що вам знадобиться

- Комп'ютер на **macOS** або **Windows**
- Ваш акаунт у **Telegram** (краще запасний) із доступом до номера телефону
- Архів `FoxyBox-встановлення.zip`, який вам надіслали

---

## Крок 1. Розпакувати файли на Робочий стіл

Ви отримали всі файли одним архівом — `FoxyBox-встановлення.zip`
(наприклад, у Завантаженнях або в Telegram).

1. Двічі клацніть по `FoxyBox-встановлення.zip` — він розпакується, і поряд
   зʼявиться **папка FoxyBox**.
2. Перетягніть цю папку **FoxyBox** на **Робочий стіл** — щоб легко знаходити.

Усередині папки буде кілька файлів (нічого звідти не виймайте):

- `foxybox.py` — сам застосунок (сюди впишете ключі на кроці 5)
- `index.html` — вигляд застосунку, чіпати не треба
- `FoxyBox.command` — кнопка запуску (Mac) / `FoxyBox.bat` — кнопка запуску (Windows)
- `Інструкція.html` — ця сама інструкція

> **Головне правило:** усі файли мають лишатися **разом в одній папці**.
> Не перекладайте їх поодинці — FoxyBox шукає їх поруч.

---
## Крок 2. Встановити Python

Python — це «двигун», на якому працює FoxyBox. Можливо, він уже є.

> **Що таке Термінал?** Це вбудована програма (на Mac — «Термінал», на Windows —
> «Командний рядок»), де замість кнопок ви вводите короткі команди текстом.
> Лякатись не варто: ви лише вставлятимете готові рядки звідси, а комп'ютер усе
> зробить сам.
>
> **Як відкрити на Mac:** натисніть `Cmd + Пробіл` (з'явиться пошук Spotlight),
> наберіть слово **Термінал** і натисніть Enter.
> **Як відкрити на Windows:** натисніть клавішу **Windows** (значок «Пуск»),
> наберіть `cmd` і натисніть Enter.

1. Відкрийте **Термінал** (Mac) або **Командний рядок** (Windows) — як описано вище.
2. Вставте цей рядок і натисніть Enter:
   ```
   python3 --version
   ```
3. Якщо побачите щось на кшталт `Python 3.10.0` (головне — число **3.9 або вище**) — Python вже є, **переходьте до наступного кроку**.
4. Якщо побачите помилку або «command not found»:
   - зайдіть на **https://www.python.org/downloads/**
   - натисніть велику жовту кнопку **Download Python** (завантажиться файл `.pkg`)
   - відкрийте завантажений файл і встановіть, тиснучи **Continue → Agree → Install**
   - після встановлення знову перевірте: `python3 --version`

---
## Крок 3. Встановити Telethon

Telethon — бібліотека, через яку FoxyBox спілкується з Telegram.

У Терміналі вставте і натисніть Enter:
```
pip3 install telethon
```
Зачекайте кілька секунд. Наприкінці має з'явитися рядок `Successfully installed telethon-...`. Якщо так — готово.

---
## Крок 4. Отримати два ключі від Telegram

Щоб застосунок міг заходити у ваш Telegram, потрібні `api_id` і `api_hash`.
Їх безкоштовно видає сам Telegram.

1. Відкрийте в браузері **https://my.telegram.org**
2. Введіть номер телефону вашого акаунта (краще запасного) у форматі `+380...`
   У Telegram прийде **код** — введіть його на сайті.
3. Натисніть **API development tools**.
4. У формі «Create new application» заповніть **тільки два поля**:
   - **App title:** `FoxyBox`
   - **Short name:** `foxybox`
   - **URL, Description та інші поля — лишіть порожніми**
   - Platform — можна обрати `Desktop`
5. Натисніть **Create application**.
6. Відкриється сторінка з ключами. Вам потрібні два значення:
   - **`api_id`** — коротке число (7–8 цифр)
   - **`api_hash`** — довгий рядок із букв і цифр

Скопіюйте обидва — вони знадобляться на наступному кроці.

> 🔒 Ці ключі приватні. Нікому не пересилайте, нікуди не викладайте.

---
## Крок 5. Вписати ключі у програму

1. Відкрийте файл `foxybox.py` у будь-якому текстовому редакторі
   *(права кнопка по файлу → «Відкрити в програмі» → TextEdit).*
2. Зверху знайдіть два рядки:
   ```python
   API_ID = 0                     # <-- сюди число
   API_HASH = ""                  # <-- сюди рядок
   ```
3. Впишіть свої значення. Число — без лапок, рядок — **у лапках**:
   ```python
   API_ID = 1234567
   API_HASH = "ВАШ_ХЕШ_СЮДИ_У_ЛАПКАХ"
   ```
   *(це лише приклад формату — підставте свої з попереднього кроку)*
4. Збережіть файл (`Cmd + S`) і закрийте редактор.

---
## Крок 6. Перший запуск і вхід у Telegram

Це одноразовий вхід. Далі FoxyBox його запам'ятає.

1. Двічі клацніть по файлу **`FoxyBox.command`**.
   Відкриється чорне вікно Терміналу — це нормально.

   > Якщо macOS каже, що не може відкрити файл «від невідомого розробника»:
   > клацніть по `FoxyBox.command` **правою кнопкою → Відкрити → Відкрити**.
   > Достатньо зробити це один раз.

2. У вікні Терміналу з'являться запитання. Відповідайте так:

   | Термінал запитає | Що ввести |
   |---|---|
   | `Номер телефону (формат +380...):` | ваш номер, напр. `+380671234567`, і Enter |
   | `Код із Telegram:` | код, що прийде **у самому Telegram** (не SMS), і Enter |
   | `Хмарний пароль (двоетапна перевірка):` | якщо у вас увімкнена двоетапна перевірка — введіть цей пароль; якщо ні — просто Enter |

   > Під час введення пароля літери на екрані **не показуються** — це нормально, просто друкуйте і тисніть Enter.

3. Побачите **«Готово! Ви увійшли»** — і автоматично відкриється браузер із FoxyBox. Готово! 🎉

---

## Як користуватись

1. **Запуск:** двічі клацніть `FoxyBox.command`. За кілька секунд відкриється браузер. Вхід більше не питатиме.
2. **Розсилка:**
   - вставте **текст пічу** (опис вакансії своїми словами);
   - вставте **список @username**, по одному в рядку;
   - натисніть **«Запустити розсилку»**.
   FoxyBox сам зробить паузи, вестиме базу й рахуватиме ліміт.
3. **База контактів:** внизу сторінки посилання «Дані по контактах зберігаються тут».
4. **Зупинити:** закрийте вікно Терміналу або натисніть у ньому `Ctrl + C`.

> **Нічого «програмувати» чи вставляти жодних «промтів» не треба.** Єдине, що ви
> вписуєте у застосунок, — свій текст вакансії та список @username. Це все.

> 🧪 **Порада для першого разу:** спершу впишіть у список **свій власний
> @username** і надішліть повідомлення собі — воно прийде у ваші «Збережені
> повідомлення». Так ви безпечно переконаєтесь, що все працює, нікого не
> потурбувавши.

## Що вбудовано для безпеки

- 🛑 Ліміт **30 повідомлень на день** (скидається о 00:00 CET)
- ⏱️ Паузи **18–24 секунди** між відправками
- ⚠️ Автоматична зупинка на **PeerFlood / FloodWait** із поясненням
- ⏭️ Неіснуючі юзернейми й закрита приватність — просто пропускаються
- 🧪 Тестовий режим без реальної відправки (для перевірки):
  у Терміналі перейдіть у папку і запустіть
  ```
  FOXYBOX_DRY=1 python3 foxybox.py
  ```

## Якщо щось пішло не так

**Браузер не відкрився / вікно Терміналу закрилось із помилкою.**
Найчастіше це збій входу. Відкрийте файл `foxybox.log` у папці — в останніх
рядках буде причина. Найпоширеніше нижче.

**Пише про невірний пароль (PasswordHashInvalidError).**
На акаунті увімкнена двоетапна перевірка, а на кроці пароля ви натиснули Enter.
Запустіть ще раз і на запиті `Хмарний пароль` введіть свій **хмарний пароль
Telegram** (той, що ви задавали в Налаштування → Конфіденційність → Двоетапна
перевірка). Це не код і не пароль від пошти.

**Код не приймається / просить почати спочатку.**
Старий код стає недійсним. Запустіть `FoxyBox.command` заново і введіть
**новий** код, що прийде в Telegram.

**Пише «FoxyBox вже працює».**
Значить, движок уже запущено — просто відкрийте в браузері адресу
`http://127.0.0.1:8770`.

**Подвійний клік по `FoxyBox.command` нічого не робить.**
Відкрийте Термінал, перетягніть у нього папку FoxyBox після слова `cd `,
натисніть Enter, потім вставте:
```
python3 foxybox.py
```

**«command not found: python3».**
Python не встановлено або встановлено не повністю — поверніться до кроку 1.

## 🪟 Якщо у вас Windows

FoxyBox працює й на Windows. Робіть **ті самі 6 кроків**, що вище, але з трьома
відмінностями:

1. **Команди — без «3».** Скрізь, де в інструкції написано `python3` чи `pip3`,
   у Windows пишіть `python` і `pip`. Наприклад:
   ```
   python --version
   pip install telethon
   ```
   > Під час встановлення Python з python.org обов'язково поставте галочку
   > **«Add Python to PATH»** на першому екрані інсталятора.

2. **Додатковий пакет `tzdata`.** У Windows нема системної бази часових поясів,
   тож доставте її одною командою (потрібно для скидання ліміту о 00:00 CET):
   ```
   pip install tzdata
   ```
   *(якщо забудете — FoxyBox сам нагадає про цю команду при запуску)*

3. **Ярлик — інший файл.** Замість `FoxyBox.command` у Windows запускайте
   **`FoxyBox.bat`** (він уже лежить у папці). Двічі клацнули — відкриється
   вікно з чорним фоном, далі все як на Mac: номер, код, за потреби хмарний
   пароль.

Решта — отримання ключів на my.telegram.org, вписування їх у `foxybox.py`,
щоденне користування — **однакові** для Mac і Windows.

> Порада для Windows: якщо подвійний клік по `FoxyBox.bat` показує помилку і
> швидко зникає — запустіть його правою кнопкою → «Запуск від імені
> адміністратора» не потрібен; просто вікно тепер лишається відкритим завдяки
> рядку `pause`, тож ви побачите текст помилки.
