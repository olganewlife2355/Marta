# 🦊 FoxyBox: встановлення за 5 кроків

FoxyBox допомагає надіслати перше повідомлення кандидатам у Telegram з вашого
акаунта. Працює **на вашому комп'ютері**: дані кандидатів нікуди, крім Telegram,
не передаються.

Нижче інструкція для **macOS**. Для **Windows** є три відмінності, вони в розділі
[«Якщо у вас Windows»](#-якщо-у-вас-windows). Займає **10–15 хвилин**,
технічні знання не потрібні.

> ⚠️ **Безпека акаунта (прочитайте перед початком)**
> Telegram обмежує акаунти, з яких масово пишуть незнайомим людям. Тому:
> - пишіть лише тим, кому вакансія справді підходить;
> - тримайте **до 20–30 повідомлень на день**, паузи не скорочуйте;
> - великі списки розбивайте на кілька днів;
> - якщо FoxyBox зупинився з повідомленням **PeerFlood**: пауза 1–2 дні.

---

## Що знадобиться

- Mac або комп'ютер з Windows
- Telegram-акаунт і телефон із цим акаунтом поруч
- Архів `FoxyBox-встановлення.zip`

> **Як вставляти команди.** Усі команди нижче готові: скопіюйте рядок,
> вставте у Термінал і натисніть Enter. Нічого вигадувати не треба.

---

## Крок 1. Розпакувати архів

1. Двічі клацніть `FoxyBox-встановлення.zip`. Поруч з'явиться **папка FoxyBox**.
2. Перетягніть папку **FoxyBox** на **Робочий стіл**.

Що в папці:

| Файл | Що це |
|---|---|
| `foxybox.py` | сам застосунок, **відкривати й редагувати не треба** |
| `index.html` | вигляд застосунку |
| `FoxyBox.command` | кнопка запуску (Mac) |
| `FoxyBox.bat` | кнопка запуску (Windows) |
| `Інструкція.html` | ця інструкція |

> **Головне правило:** усі файли лежать **разом в одній папці**. Не виймайте їх
> поодинці.

---

## Крок 2. Встановити Python

Python потрібен, щоб FoxyBox працював. Можливо, він уже є.

1. Відкрийте **Термінал**: `Cmd + Пробіл`, наберіть `Термінал`, Enter.
2. Вставте і натисніть Enter:
   ```
   python3 --version
   ```
3. Бачите `Python 3.9` або вище (наприклад `Python 3.12.4`): переходьте до кроку 3.
4. Бачите помилку або `command not found`:
   - відкрийте **https://www.python.org/downloads/**;
   - натисніть жовту кнопку **Download Python**;
   - відкрийте завантажений файл `.pkg`: **Continue → Agree → Install**;
   - закрийте й знову відкрийте Термінал, повторіть `python3 --version`.

---

## Крок 3. Встановити Telethon

Telethon: бібліотека, через яку FoxyBox працює з Telegram. У тому ж Терміналі:
```
python3 -m pip install telethon
```
Наприкінці має з'явитися `Successfully installed telethon-...`. Готово.

> Якщо бачите помилку `externally-managed-environment`, вставте замість цього:
> ```
> python3 -m pip install --user --break-system-packages telethon
> ```

---

## Крок 4. Отримати два ключі від Telegram

FoxyBox потрібні `api_id` і `api_hash`. Їх безкоштовно видає Telegram.

1. Відкрийте **https://my.telegram.org**.
2. Введіть номер телефону у форматі `+380...`. Код прийде **у Telegram** (не SMS).
3. Натисніть **API development tools**.
4. Заповніть лише два поля:
   - **App title:** `FoxyBox`
   - **Short name:** `foxybox`
   - Platform: `Desktop`, решту лишіть порожнім
5. Натисніть **Create application**.
6. Тримайте сторінку відкритою: на ній два значення, вони знадобляться на кроці 5.
   - **`api_id`**: коротке число (7–8 цифр)
   - **`api_hash`**: рядок із 32 літер і цифр

> 🔒 Ключі приватні: нікому не пересилайте.
> Якщо сайт показує `ERROR` при створенні застосунку, спробуйте пізніше або з
> іншого браузера. Це обмеження на стороні Telegram.

---

## Крок 5. Перший запуск

1. Двічі клацніть **`FoxyBox.command`**. Відкриється вікно Терміналу.
2. Відповідайте на запитання:

   | Термінал запитає | Що ввести |
   |---|---|
   | `api_id (коротке число):` | число з my.telegram.org, Enter |
   | `api_hash (довгий рядок):` | рядок з my.telegram.org, Enter |
   | `Номер телефону (формат +380...):` | ваш номер, напр. `+380671234567`, Enter |
   | `Код із Telegram:` | код, що прийшов **у Telegram**, Enter |
   | `Хмарний пароль (двоетапна перевірка):` | ваш хмарний пароль, якщо він є; якщо ні, просто Enter |

   > Пароль під час введення не видно. Це нормально: друкуйте і тисніть Enter.

3. Побачите **«Готово! Ви увійшли»**, і браузер відкриє FoxyBox. 🎉

Ключі й вхід FoxyBox запам'ятовує: наступного разу нічого вводити не треба.

> **Якщо macOS не відкриває файл** («невідомий розробник» або «немає дозволу»):
> - клацніть по `FoxyBox.command` правою кнопкою → **Відкрити** → **Відкрити**;
> - якщо кнопки «Відкрити» немає: **Системні параметри → Конфіденційність і
>   безпека**, внизу натисніть **«Усе одно відкрити»**;
> - якщо пише «немає дозволу», один раз вставте в Термінал
>   `chmod +x ~/Desktop/FoxyBox/FoxyBox.command` і спробуйте знову.

---

## Як користуватись

1. **Запуск:** двічі клацніть `FoxyBox.command`. Браузер відкриється сам.
2. **Розсилка:**
   - у перше поле впишіть **текст повідомлення** (вакансія своїми словами);
   - у друге: **@username кандидатів**, по одному в рядку;
   - натисніть **«Запустити розсилку»**.
3. **Повторно FoxyBox не пише.** Кандидатів, яким уже писали, він пропускає й
   показує це в журналі.
4. **База контактів:** посилання «Дані по контактах зберігаються тут» унизу сторінки.
5. **Зупинити:** закрийте вікно Терміналу або натисніть у ньому `Ctrl + C`.
   Просто закрити вкладку браузера **недостатньо**: розсилка продовжиться.

> 🧪 **Перший раз:** впишіть у список **свій** @username. Повідомлення прийде у
> ваші «Збережені повідомлення», і ви переконаєтесь, що все працює.

---

## Що вбудовано для безпеки

- 🛑 Не більше **30 повідомлень на день** (ліміт скидається опівночі за
  центральноєвропейським часом)
- ⏱️ Пауза **18–24 секунди** між повідомленнями
- 🔁 Кому вже писали, повторно не пише
- ⚠️ Автоматична зупинка на **PeerFlood / FloodWait** з поясненням
- ⏭️ Неіснуючі юзернейми та закриту приватність пропускає
- 🔐 Керувати FoxyBox може лише його власна сторінка: сторонні сайти в
  браузері не можуть запустити розсилку
- 🧪 **Тестовий режим**: нічого не надсилає, не витрачає ліміт і не пише в базу.
  У Терміналі:
  ```
  cd ~/Desktop/FoxyBox
  FOXYBOX_DRY=1 python3 foxybox.py
  ```

## Якщо щось пішло не так

**Вікно Терміналу закрилось або браузер не відкрився.**
Відкрийте `foxybox.log` у папці FoxyBox: в останніх рядках буде причина.

**«Telegram не прийняв api_id / api_hash».**
Запустіть FoxyBox ще раз: він знову запитає ключі. Скопіюйте їх з
my.telegram.org уважно, без пробілів.

**PasswordHashInvalidError (невірний пароль).**
На акаунті є двоетапна перевірка, а ви натиснули Enter без пароля. Запустіть ще
раз і введіть **хмарний пароль Telegram** (Налаштування → Конфіденційність →
Двоетапна перевірка). Це не код і не пароль від пошти.

**Код не приймається.**
Код діє недовго. Запустіть FoxyBox заново і введіть **новий** код.

**«Сторінка застаріла. Оновіть її».**
FoxyBox перезапускали. Оновіть вкладку: `Cmd + R`.

**«FoxyBox вже працює».**
Він уже запущений: відкрийте в браузері `http://127.0.0.1:8770`.

**Подвійний клік нічого не робить.**
У Терміналі вставте по черзі:
```
cd ~/Desktop/FoxyBox
python3 foxybox.py
```

**`command not found: python3`.**
Python не встановлено: поверніться до **кроку 2**.

## 🪟 Якщо у вас Windows

Ті самі 5 кроків, але:

1. **Термінал = Командний рядок.** Клавіша **Windows**, наберіть `cmd`, Enter.
   Команди пишіть **без «3»**:
   ```
   python --version
   python -m pip install telethon tzdata
   ```
   Під час встановлення Python з python.org поставте галочку **«Add Python to
   PATH»** на першому екрані. `tzdata` потрібен для денного ліміту.
2. **Запуск:** замість `FoxyBox.command` двічі клацайте **`FoxyBox.bat`**. Якщо
   Windows показує «SmartScreen»: **Докладніше → Виконати в будь-якому разі**.
3. **Тестовий режим** у Командному рядку:
   ```
   cd %USERPROFILE%\Desktop\FoxyBox
   set FOXYBOX_DRY=1
   python foxybox.py
   ```

Отримання ключів, вхід і щоденна робота однакові для Mac і Windows.

## Приватні файли (нікому не пересилати)

- `foxybox_config.json`: ваші ключі `api_id` / `api_hash`
- `foxybox_session.session`: ваш вхід у Telegram (хто має цей файл, той має
  доступ до акаунта)
- `foxybox_db.json`: база кандидатів

Решту файлів (`foxybox.py`, `index.html`, ярлики запуску, інструкцію) можна
передавати колегам: ключів у них немає.
